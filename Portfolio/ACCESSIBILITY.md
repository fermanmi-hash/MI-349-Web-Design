My original accessibility score was a 92%. The reason it gave was by font colors were clashing dark font colors with dark font colors
because of htis I just had to add some simple code at the very bottom that would adjust the color of the footer and the font color inside of said footer 

   #projects article {
        background-color: #d5e8e2;
        color:#184538;
    }

    #projects article h3 {
        color: #184538;
    }

    #projects article p {
        color: #184538;
    }

    footer {
        background-color: #184538;
    }

    footer p {
        color: #ffffff;


this is the code that I added to fix the problem I was having.

Once the problem was fixed I was given a 100% accessibility score
